4. Tell me about a production mistake (STAR, 2 min)

  1. At The Penny Hoarder, I was leading the HTTP to HTTPS conversion when pages started loading without CSS intermittently - they'd render but look completely broken.
  2. I traced it to a CloudFront caching issue where certain iOS versions would cache pages with http:// stylesheet links, and whichever device hit first determined the cache for everyone.
  3. I fixed it by correcting the server-level cache before it reached CloudFront, ensuring all devices got proper HTTPS references, then invalidated CloudFront to clear the bad cache.
  4. Now I always test cross-device caching behavior before any protocol or CDN changes.
